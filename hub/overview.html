arikkfir-org hub

A personal development hub on one private GKE cluster in me-west1. Terraform provisions it, Argo CD runs it from Git, Octomatron turns GitHub events into Tekton pipelines, and everything internal sits behind a single sign-in. Facts and names: reference. Bring-up: runbook.

Flows

Change code

  1. Linear issue
  2. branch
  3. pull request
  4. Octomatron runs ci
  5. 1 approval
  6. merge queue runs ci again
  7. squash into main

Release and deploy

  1. tag vX.Y.Z
  2. Octomatron release
  3. image in Artifact Registry
  4. pull request to delivery
  5. Argo CD syncs

Sign in

  1. open argocd.kfirs.com
  2. Traefik ForwardAuth
  3. oauth2-proxy
  4. Descope + Google
  5. callback on auth.kfirs.com
  6. email allowlisted?
  7. cookie for .kfirs.com

Publish docs

  1. push to docs/main
  2. Octomatron publish
  3. render changed Markdown
  4. rsync to arikkfir-docs
  5. direct links

Claude Code session

  1. environment setup script
  2. setup.sh from arikkfir-claude
  3. verify bundle
  4. ~/.claude: CLAUDE.md, hooks
